# PilotServerDataExtraction

Консольное приложени на С# предназначенное для выгрузки данных из Аскон Pilot Server 25.1.0.53184 и сохранении их в выбранной директории (по умолчнаю настроено на "Рабочий стол" текущего пользователя Windows

В работе приложения использованы следующие данные пакеты NuGet:

	* Ascon.Pilot.SDK 23.16.0
    * Ascon.Pilot.Server.Api 23.16.0
    * Ascon.Pilot.ServerExtensions.SDK 23.16.0

1. Подключение к БД и аутентификация
	
	Для доступа к Бд нужно вести следующие данные:
	
	- url адрес сервера Pilot в виде: https://pilot-bim.rain.ru:2491
	- имя базы данных Pilot к которой выполняется подключение: "FAIRYTALE"
	- логин пользователя 
		* в доменном формате: "RAIN\\\k.lapkin"
		* в обычном формате: "root_admin"
	- пароль пользователя

	Данные вносятся напрямую в код (строки 49 - 51).

2. Фильтрация данных в запросе

	Фильтрация данных происходит по двум параметам: 

	* Идентификатор "GUID" родительской папки. Будут выгружены все материалы в данной папке. Данные по папке самой папке выгружены не будут. Найти GUID папки можно скопоровав ссылку из настольного клиента.
		- Указывается в строке 54.
	* Идентификаторы типов сущностей (папок, файлов, документов). Будут выгружены все типы внутри указанной папки. Данные об идентификаторах можно получить из приложения Pilot-myAdmin в свойствах базы данных.
		- Указывается списком через запятую через в строках 59-63.
